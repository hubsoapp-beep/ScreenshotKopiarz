# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| latest (main) | ✅ |
| older releases | ❌ |

## Reporting a Vulnerability

ScreenshotKopiarz runs locally and does not send data anywhere. It only reads files in observed folders and writes to the system clipboard.

If you discover a security issue (for example, a path traversal, unsafe file handling, or a crash that could be triggered by a crafted filename), please **do not** open a public issue.

Instead, email the maintainer or open a private advisory via GitHub: `Security` tab → `Report a vulnerability`.

You can expect an initial response within 7 days. If the issue is confirmed, a fix will be released as soon as possible and credited to the reporter (unless anonymity is requested).
